## Before presenting

Use the presenting Mac and Chrome window for a short rehearsal. Open Cases and Knowledge once, then open the chosen example and its source before starting the presentation. This gives sleeping hosting time to wake and confirms the exact routes you will show. If the page shows **Saved copy · refresh failed** or **Saved copy · refreshing**, describe the displayed information as a retained browser copy.

## Suggested five-minute sequence

1. Use a desktop window around 1440 × 900. Open Demonstration and choose **Watch the analysis**, or use the autoplay presentation link above. The recorded presentation lasts 88.05 seconds and covers the customer, reading, process, decision, learning, and cases.
2. Pause, resume, or use **Skip to answer** as needed. At the end, **Resume** restarts the film.
3. Open the example **An increase form with missing original reasons**:
   https://casepath-autonomous.kumarnavish.chatgpt.site/#autonomous/claim/clm_543f08f2415b2a33
4. Select **Claim reader**, open a cited passage, and show the exact highlighted source span. Use **Open full source** to inspect the document.
5. Select **Process builder** and **Show the reasoning** to follow the linked checks and source material. Select **Result checker**, then open the assessment or draft letter.
6. Point out **Not sent — you decide**. Use **Edit a copy → Save on this device → View original**. Viewing the original changes what is displayed and preserves the edited copy saved on this device; reopening the draft can show that saved copy again. This does not send anything.
7. Open **Knowledge** to show versions and the contributing and receiving cases. Use **How this was learned** and **History**.
8. For a saved original investigation, open **Competing notices and an alleged correction**:
   https://casepath-autonomous.kumarnavish.chatgpt.site/#autonomous/claim/clm_0c5e7c7723a3c694
   Open **History** to show the saved sequence.

## How to describe the demonstration

The presentation uses recorded analysis of fictional cases. The collection contains 159 intakes: 150 canonical intakes and nine additional native intakes. Nine selected original cases have saved investigation histories. The nine curated reference examples are a separate demonstration selection, with one case shared with the original nine. These counts do not mean that all 159 intakes have saved investigations. The public site supports review of saved cases, sources, histories, and Knowledge. The public demo is view only: it reviews and replays saved work and does not start new investigations or send messages. Draft edits are saved only in the current browser. The original nine saved workflows are preserved and should not be restarted.

## If a request is interrupted

Give the bounded automatic retry time to finish. If the page offers **Try again**, use that control. A failed browser refresh can leave a retained copy visible with a **Saved copy** status. The service can also return a previously verified response during a temporary storage failure; this is distinguished in response metadata and the verification evidence, and can render as a normal page. Neither form of recovery starts a new investigation.
