## Points for a jurist

1. **014 (g014, kept).** Does the CSS claim form's "Beschädigte oder gestohlene Sachen (bitte Originalkaufbelege beilegen)" (0176) amount to a standing request ("Verlangen") for original vouchers for every listed item? Or are vouchers due only on a specific request, as the AVB say ("auf Verlangen ... Originalbelege beizubringen", 0048/0134)? If only on request, narrow the condition to "The insurer has requested original purchase vouchers (or other specified documents) for the affected items." As the condition stands, its second arm ("the claim concerns damaged or stolen items") makes D05 due in every theft claim. This is the open review-queue item 014.
2. **073 (g073, narrowed).** Passage 0153 is a bare heading fragment (heading `css-avb-519d-0224-cl26`). Which CSS cover does it belong to? Is that cover theft excluding simple theft? The narrowed condition is literal to the fragment, and the jurist should confirm it.
3. **004 / 004.a (g004, split).** Should the duty to obtain the insurer's instruction (VVG Art. 38a, 0116) count as triggered in every claim, through the notification itself? Or only where mitigation, preservation or rescue measures were actually to be taken, which is how it was narrowed here? The question from the earlier review queue (004) also remains open: should the perpetrator-identification and recovery measures (0056, 0099, under the theft clauses) apply after any insured event, or only after theft? The question is now moot for this pack, because f01 is unconditional in a theft workflow.
4. **003 (g003, narrowed).** The narrowed condition includes 'help services engaged on the damaged items'. That arm comes from Simpego 0096 only ("Hilfeleistungen in Anspruch genommen"). Does it apply under the other insurers' terms? The condition deliberately does not exclude changes made for loss mitigation or in the public interest. The VVG/CSS/SVV/Generali passages allow those changes without consent, but the trace clauses (0043, 0127) and Simpego 0096 do not. The rule's facts already accept a mitigation or public-interest justification. Should D27 still be requested when a change was made for mitigation only? (Review-queue item 003.)
5. **042 (g042, narrowed).** Confirm that a thief who has not been identified is not a 'Dritter' against whom claims 'geltend machen könnte' (0055) or recourse can be 'sichergestellt' (0165). Confirm that an identified or caught thief does count.
6. **002 (g002, made unconditional).** The open review-queue item remains. CSS calls for the police report only on request ("kann durch die CSS einverlangt werden", 0043), while police notification is a duty in every theft. Should D07 be the evidence of notification for every insurer?
