Branch-intervention benchmark

Twenty-seven held-out case pairs. The two versions of a pair differ in one sentence that decides which source rule applies. Each system is scored on the change between the two document checklists it produces, never on either checklist alone. Click a pair to see what changed and what each system asked for.

Marks come from the frozen scorer's preserved held-out report: for each pair and system the reference realisation shown is the one the scorer selected, so the counts here are exactly the ones the paper reports. Where a requirement admits alternative routes, satisfying one is correct and adding the other is a spurious request. Rebuild this page's data with python3 build_explorer_data.py; recompute every score with python3 reproduce.py.
