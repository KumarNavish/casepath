# Compact conditional-planning comparison — prospective contract

This increment supplies executable preparation, wire decoding, request rendering,
and adapters. It does not admit, reserve or execute provider inference and cannot
score the protected benchmark. Historical V5 and the native factorial remain
unchanged. The five learned arms remain CASEPATH_CONTROL, DIRECT_REVIEWED,
DOCUMENT_FIRST_REVIEWED, PROCESS_CONTEXT_REVIEWED and RULE_FIRST_REVIEWED.
The unrecovered historical kernel is explicitly excluded, never rebranded as
Rule-First. Two additional deterministic rows share fresh control assessment.

## Scientific question and preparation

The estimand is case assessment and planning **conditional on the same compiled
public representation**, not end-to-end source-to-process superiority. The actual
three public templates are compiled with no model and no claim inputs. Their
source assertions are resolved in the public registry. Catalogue document duties
become evidence-state capabilities; these task labels are declared deterministic
adaptation, not inferred substantive facts. No extra alternative proof routes,
action prerequisites, legal entailment or case routing answer is invented.
Temporal transitions remain native graph relations; they are not silently turned
into acquisition prerequisites. The source-preparation manifest and full planning
objects remain preserved. All three domains and the same source material are
supplied to every learned arm.

## Reversible native wire, not lossy checklist shorthand

`Book` builds public native prototype tables c/r/b/d. Every selected object must
be stated by the model. No omitted row is automatically added. Native concepts,
relations and predicates are selected by index, optionally with explicit field
edits; each document selection always states its state and request mode. A full
literal row is permitted for new objects or corrections. Explicit aliases expand
native endpoints, expressions and source locators. Confidence and invalid source
choices are not silently repaired. Decoding calls the unchanged original native
schema and expression parser. Exactness means equality of the normalized native
artifact; original JSON whitespace and omitted schema-default fields are not
preserved. The **full planning -> native artifact** mapping remains a projection,
so full route grouping and joint-adequacy objects are retained separately.

The shared input view preserves every source assertion via a sentence expansion
formula or literal override, authority text, full text-projected case material,
attachment inventory and extraction coverage. It does not repeatedly verbalize
long cryptographic hashes/paths, which remain bound in immutable source and codec
records. This is a declared semantic input projection, not the legacy byte-for-byte
model prompt. JPEGs remain opaque; PDF text extraction is not visual reading.

## Finite equal generation contract

All learned conditions use two calls per singleton case, one sample, the same
model/returned model, standard provider route and medium reasoning. Temperature
is not sent and its effective setting remains unverified. First call emits a
complete draft plus bounded notes according to the assigned ordering. Review gets
the entire same input and complete normalized draft, may correct every field, and
returns a complete response. JSON normalization removes whitespace only; raw
responses and exact raw parent hashes are still retained. No truncation,
resampling or automatic model repair is allowed. Every failed cell remains in the
intention-to-evaluate population with the frozen native failure treatment.

Common limits: 4,096 total completion tokens; 24,576 raw response bytes; 6,144
normalized draft bytes; 1,536 note bytes; 16,384 normalized final bytes. These are
prospective changes applied to every arm, not a claim of legacy factorial fidelity.
The complete all-three-template native object (125 concepts, 131 relations,
38 predicates, 27 document entries) serializes to 1,243 compact bytes and expands
to 167,517 normalized native bytes in the observed projection. A dense engineering
state over all 50 variables, all 27 documents, 31 slot assessments and 31 joint
assessments occupies 2,162 compact bytes, or 3,720 bytes with wrapper and maximum
notes. These witnesses establish representational capacity, not real model
reasoning performance. Literal customization can cost more; bounded-output failures
are retained and no successful generation is guaranteed.

## Reservation and tokenizer boundary

The complete rendered schedule has 1,502 provider slots: 1,500 case calls and two
excluded route/parameter checks. Source preparation is zero-provider. The reviewed
standard endpoint rates are 2e-6 input, 12e-6 output, 0.2e-6 cache-read and 2.5e-6
cache-write dollars/token. Reserve MAX input category (2.5e-6), never their sum, and
assume no cache hits. Web/tool calls and long-context pricing are excluded.

Count fixed message text plus the entire worst legal prior draft, not unused
200k input capacity. The counter is UTF-8 text-byte upper bounds plus the retained
4,096-token framing allowance, **not observed native tokenization**. No exact
Terra tokenizer/framing binding has been verified here; the existing independent
canonical token-bound attestation remains required before any send. The official
openai/tiktoken model mapping uses a generic GPT-5 prefix; that does not itself
verify this precise third-party endpoint or chat framing.
