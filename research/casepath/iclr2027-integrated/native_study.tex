\section{Study B: Complete Claims, Executability and Request Quality}
\label{sec:native}

\paragraph{A matched complete-corpus comparison.}
Study~B evaluates all \nbClaims{} released synthetic tenancy claims across
\nbFamilies{} families and three domains: defects, mould and heating;
termination; and rent increase. Development contains \nbDevClaims{} claims
in \nbDevFamilies{} families; the protected split contains \nbHidClaims{}
claims in \nbHidFamilies{} disjoint families. Five learned pipelines share
the compiled public representation, observable case packet, source access,
model alias and budget: \nbCallsPerCell{} calls per cell, \nbReasoning{}
reasoning, \nbTokens{} completion tokens per call, no tools or resampling.
\casepath emits an assessment that code compiles into the artefact;
Direct, Document-first, Process-context and Rule-first generate the artefact.
The compiled-equivalent and local-scope controls reuse \casepath's
assessments, adding no independent model trials. This tests complete pipelines
under matched information and budget, rather than isolating a prompting order.

\paragraph{Registered primary: a common interface failure.}
The complete \nbCells-cell evaluation retains \nrArtifactFailures{}
generated artefacts and \nrRequestPenalties{} failed or blocked outputs.
Every generated artefact encounters native evaluation failures: the public
compiler's condition names are not bound in the native reference scenario.
A target-blind census finds \nrNativeSymbols{} distinct symbols, all from
the common compiler; no public, meaning-preserving translation is established.
The frozen policy therefore assigns adverse penalties to every cell, and
\nrPrimaryMet{} of \nrPrimaryTotal{} protected-split practical targets are
met. These zeros and ones are policy penalties. They do not show that every
requested document was wrong or that the pipelines had equal request quality.
The complete primary report, failure messages and unchanged evaluator are
included in the release.

\paragraph{Post-hoc diagnostic: what did the systems actually request?}
A separate analysis scores the literal immediate-request lists in the saved
artefacts against the original generator-assigned document sets. It uses the
original reference and request-counting functions, with no graph repair,
guard interpretation or new model calls. All \nrRequestObserved{}
generated lists are scoreable; the \nrRequestPenalties{} failed or blocked
outputs retain zero precision, recall, $F_1$ and exact accuracy, and an
unnecessary-fraction penalty of one. Their raw request counts remain
unavailable. This diagnostic was specified after the interface failure and
is reported separately from the registered comparison.

\casepath produces \rqHidCpN{} request lists on the protected split,
compared with \rqHidDirN, \rqHidDocN, \rqHidPcN{} and \rqHidRfN{} for the
learned alternatives. Its failure-penalized $F_1$ is \rqHidCpF{} against
\rqHidPcF{} for the strongest comparator, Process-context
(Table~\ref{tab:native-final}); on the combined corpus, \casepath scores
\rqAllCpF{} against \rqAllRfF{} for the strongest comparator there,
Rule-first. The difference includes a substantial output-availability
advantage. The \rqHidCpN{} observed \casepath lists contain
\rqHidCpCorrect{} correct requests among \rqHidCpRequested{} emitted,
with \rqHidCpMissed{} reference documents missed. Those counts describe the
observed lists only, not all \nbHidClaims{} claims.

The distinction matters for the paired result. The conventional protected
$F_1$ difference against Process-context is \rqHidDPcF. The conservative
contrast, which assigns $-1$ whenever either request-only endpoint is
unobserved, is \rqHidCPcF. Conservative contrasts remain negative against
all four learned alternatives (Appendix~\ref{app:request-diagnostic}).
The diagnostic supports better realized request output under this budget;
it does not establish reliable paired superiority.

\paragraph{Why scope matters to acquisition.}
The compiled-equivalent control reproduces \casepath's request scores
exactly. Reusing the same assessments with only local scope reduces
protected $F_1$ to \rqHidLsF{} and raises the failure-penalized unnecessary
fraction from \rqHidCpU{} to \rqHidLsU. Figure~\ref{fig:scope} connects the
ancestor-scope mechanism to what the controller emits: a locally plausible
obligation can request a document even when its enclosing branch is inactive.
It remains a dependent, post-hoc request diagnostic; it supplies no evidence
of correct native branches, valid chains or authoritative support.

All \nbClaims{} observable inputs had been inspected during product work;
``protected'' denotes target custody and family disjointness, not untouched
inputs. The producer terminated without its complete I/O audit, so historical
non-access to the protected targets is not established retrospectively, and
the target containers have since been released, so this corpus cannot serve
as newly hidden confirmation (Appendix~\ref{app:request-diagnostic}). Combined estimates recompute the domain--family--case weights.
Family-deletion ranges describe composition sensitivity, with no confidence
intervals or significance tests. Study-attributed inference cost is
\$\nrStudyCost{}; total historical spending is \$\nrTotalCost. Offline
scoring and reproduction add computation but no provider calls.
